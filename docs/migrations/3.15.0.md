# Migrating to 3.15.0

Version 3.15.0 is additive. Existing compiled artifacts, run records, adapter
files, and evaluation records remain compatible; schema versions are unchanged.

Run:

```bash
npx --yes forgeai-agentic-init@3.15.0 --upgrade
```

Normal upgrade behavior preserves customized `model-routing.yaml`,
`cli-adapters.json`, and `api-adapters.json`. To adopt the new `direct` tier or
the bundled `gemini-direct` adapter in an existing project, merge those entries
from the package templates deliberately rather than using `--force`.

The new `--system-one-route --signals <json-file>` command is experimental and
does not call a model itself. Supply calibrated outputs from Jev or another
structured classifier, inspect the typed decision, and measure it against your
existing routing baseline before connecting it to automatic execution.
