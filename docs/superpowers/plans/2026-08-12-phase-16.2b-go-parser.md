## Known design decisions (verified before writing tasks)

**Import path extraction uses `maskComments(line.text, inBlockCommentBefore)`.**
`scanLine()` strips string interiors from `effective`, so import paths (which live inside strings) must be extracted from `line.text`. But `line.text` also contains comment text; a regex on the raw text would match strings inside comments. The `maskComments(text, startInBlock)` helper walks character-by-character, replacing comment regions with spaces while preserving string literals. `inBlockCommentBefore` (captured in `LineInfo` before each `scanLine` call) provides the initial block-comment state so that lines inside a multi-line `/* */` are handled correctly — including the case where `/*` opens on the same line as a fake path (not covered by a boolean flag alone).

**Grouped import block handling precedes the `isAtTopLevel` guard.**
Lines inside an `import (...)` block have `parenDepthBefore=1`, so they fail `isAtTopLevel`. The `inImportBlock` branch must appear **before** the guard, not after it, or grouped imports are silently dropped.

**Top-level tracking uses three depth counters (brace + paren + bracket).**
A line at brace-depth 0 but inside a multi-line parameter list (`func Foo(\n\targ int,\n)`) must NOT be treated as top-level, or `spanEnd()` would terminate the span prematurely. `ScanState` and `LineInfo` track `parenDepth` and `bracketDepth` as well as `braceDepth`; `isAtTopLevel()` requires all three to be 0.

**`spanEnd` stops at top-level comment lines, not only at non-empty effective lines.**
A doc-comment line like `// B docs` produces empty `effective` (the `//` causes `scanLine` to break immediately). If `spanEnd` only stops on non-empty effective content, span A would run through B's doc comment and both spans would include the same lines. The fix: also stop when the raw line starts with `//` or `/*` at top-level position.

**All declarations in `_test.go` files get `kind: 'test'`.**
The spec says "its top-level declarations are emitted with `kind: 'test'`" — this applies to `type`, `const`, and `var` as well as `func`. The `isTestFile` override is applied uniformly at the point of pushing the declaration, not only inside the `func` branch.

**Exports use `d.name` for `function` kind, `d.search_names` for all other kinds.**
A method `func (r *Repo) Save()` has `search_names: ['Save', 'Repo.Save']`. Only `Save` (the declared identifier) contributes to `exports`; `Repo.Save` is a search alias. The export loop uses `d.kind === 'function'` as the discriminator — functions use `d.name`; `class`/`type`/`variable` use all `search_names` (which is the right behaviour for grouped declarations where every name in the list is a declared identifier).

**Multi-name single-line declarations are supported.**
`const A, B = 1, 2` and `var X, Y int` are valid Go. `extractNamesFromDecl(text)` splits the left-hand side (before `=` or `:`) by comma and extracts every identifier, returning `['A', 'B']` and `['X', 'Y']` respectively. The same helper is used inside `parseGroupedNames`.

**`go.mod` is hashed into the source fingerprint.**
Changing the module path changes edge resolution without touching any `.go` file. `buildSourceInventory` includes `go.mod` content in the fingerprint hash so `checkDependencyGraphHealth` correctly reports stale after a module rename.

**Grouped `type (...)` blocks are supported.**
The spec requires grouped type declarations. Detection: `eff.slice('type'.length).trim().startsWith('(')`. Parsing: same `parseGroupedNames()` helper used for const/var.

**`parseGroupedNames()` breaks (not continues) on closing `)`.**
Using `continue` on `t === ')'` causes the scanner to run past the end of the group and absorb identifiers from subsequent declarations.

**`extractSignature` uses a `SignatureMode` parameter.**
Three modes: `'logical_line'` returns the effective header directly (const/var/type-alias/grouped); `'type_body'` scans for the body `{` and treats any `{` at depth 0 as the opener; `'function'` scans for the body `{` but adds special handling for `struct`/`interface` preceding the `{` (inline return types). This three-way distinction is necessary because named `type Config struct{}` and anonymous `func New() interface{}` have the same token sequence locally but require opposite behavior: the former must stop at `{`, the latter must continue past it.

**`extractSignature` handles `interface{}`/`struct{}` inline return types (function mode only).**
The `lastToken` check runs FIRST. Only when `lastToken === 'struct' || 'interface'` is the `{` treated specially — either as an empty inline type (peek-ahead sees `}` immediately) or as a non-empty composite type (depth incremented, scanning continues). For all other preceding tokens (including `)` from `func F() {}`), the `{` at depth 0 is unconditionally the body opener. This is never active in `'type_body'` mode, where named struct/interface bodies must terminate immediately.

**`parseGroupedNames` filters by line depth, not just by effective content.**
Only lines where `parenDepthBefore === 1 && braceDepthBefore === 0 && bracketDepthBefore === 0` are processed. This prevents: (1) inner method signatures inside `interface { Run() }` bodies (braceDepthBefore ≥ 1) from appearing as group members, and (2) the `)` that closes a nested call like `fn(1,)` (parenDepthBefore ≥ 2) from terminating the group early and losing subsequent members.

**Doc-comment attachment supports multi-line `/* */` blocks.**
`docCommentStart()` walks backward line-by-line. If the immediately-preceding line ends with `*/`, it continues walking backward until it finds the `/*` opener. The blank-line guard fires only at the outer level: if the line immediately before the declaration is blank, no doc comment is attached and the walk never starts. Blank lines that appear inside the `/* */` block itself do not stop the backward walk — the implementation intentionally walks through them to reach `/*`.

**Generic type declarations and generic method receivers are supported, including nested-bracket constraints and multi-line type-parameter lists.**
Classification uses `classifyTypeKind(lines, declLine, afterName)`: if `afterName` starts with `[`, a bracket-depth counter (not `indexOf`) scans forward to find the matching `]`. The depth counter correctly skips nested brackets such as `~[16]byte` in `[T ~[16]byte]`. If the type-parameter list spans multiple lines (e.g. `type Cache[\n  K comparable,\n]`), scanning continues on subsequent effective lines until `bracketDepth` returns to 0. Whatever follows the closing `]` on that line is then tested for `struct` / `interface` to determine the kind. For generic method receivers like `func (c *Cache[K]) Get(key K)`, the method-regex allows `(?:\[[^\]]*\])?` after the receiver type name. The `extractSignature` body-opener check requires `sigState.bracketDepth === 0` so that `{` inside a constraint like `[T interface{comparable}]` is never mistaken for the body opener.

**Identifier parsing is ASCII-only (best-effort for Unicode exports).**
The Go spec allows Unicode uppercase letters as exported identifiers (e.g. `func Écrire()`). The identifier regexes (`[A-Za-z_][A-Za-z0-9_]*`) only match ASCII names. Such identifiers are not indexed. The `isUppercase` helper is Unicode-aware, but it never receives non-ASCII names. This is a known limitation; the export check in the spec should be read as "ASCII uppercase letters" for this implementation.

```typescript
import type { SourceAnalysis, SourceDeclaration, SourceDeclarationKind, ParsedImport } from './source-analysis.js';
import type { LanguageParser, ImportResolution, ImportResolutionContext } from './language-registry.js';

// ─── scanner ─────────────────────────────────────────────────────────────────

type ScanState = {
  braceDepth: number;
  parenDepth: number;
  bracketDepth: number;
  inBlockComment: boolean;
  inInterpString: boolean;
  inRawString: boolean;
  inRune: boolean;
};

function makeState(): ScanState {
  return { braceDepth: 0, parenDepth: 0, bracketDepth: 0, inBlockComment: false, inInterpString: false, inRawString: false, inRune: false };
}

// Scan one line, update all depth counters, return effective content (strings/comments stripped).
// Import paths live inside strings and must be extracted from line.text, never from effective.
function scanLine(line: string, state: ScanState): string {
  let effective = '';
  let i = 0;
  while (i < line.length) {
    const ch = line[i];
    if (state.inBlockComment) {
      if (ch === '*' && line[i + 1] === '/') { state.inBlockComment = false; i += 2; } else i++;
      continue;
    }
    if (state.inRawString) { if (ch === '`') state.inRawString = false; i++; continue; }
    if (state.inInterpString) { if (ch === '\\') { i += 2; continue; } if (ch === '"') state.inInterpString = false; i++; continue; }
    if (state.inRune) { if (ch === '\\') { i += 2; continue; } if (ch === "'") state.inRune = false; i++; continue; }
    if (ch === '/' && line[i + 1] === '/') break;
    if (ch === '/' && line[i + 1] === '*') { state.inBlockComment = true; i += 2; continue; }
    if (ch === '`') { state.inRawString = true; i++; continue; }
    if (ch === '"') { state.inInterpString = true; i++; continue; }
    if (ch === "'") { state.inRune = true; i++; continue; }
    if (ch === '{') state.braceDepth++;
    else if (ch === '}') { if (state.braceDepth > 0) state.braceDepth--; }
    else if (ch === '(') state.parenDepth++;
    else if (ch === ')') { if (state.parenDepth > 0) state.parenDepth--; }
    else if (ch === '[') state.bracketDepth++;
    else if (ch === ']') { if (state.bracketDepth > 0) state.bracketDepth--; }
    effective += ch;
    i++;
  }
  return effective;
}

type LineInfo = {
  text: string;
  start: number;
  effective: string;
  braceDepthBefore: number;
  parenDepthBefore: number;
  bracketDepthBefore: number;
  inBlockCommentBefore: boolean;
};

function toLines(content: string): LineInfo[] {
  const lines: LineInfo[] = [];
  const state = makeState();
  let offset = 0;
  for (const text of content.split('\n')) {
    const { braceDepth, parenDepth, bracketDepth, inBlockComment } = state;
    const effective = scanLine(text, state);
    lines.push({ text, start: offset, effective, braceDepthBefore: braceDepth, parenDepthBefore: parenDepth, bracketDepthBefore: bracketDepth, inBlockCommentBefore: inBlockComment });
    offset += text.length + 1;
  }
  return lines;
}

function isAtTopLevel(line: LineInfo): boolean {
  return line.braceDepthBefore === 0 && line.parenDepthBefore === 0 && line.bracketDepthBefore === 0;
}

// ─── spans ────────────────────────────────────────────────────────────────────

// Returns the line index where a declaration's doc comment begins, or declLine if none.
// Handles contiguous `//` lines, single-line `/* */`, and multi-line `/* ... */` blocks
// (where the line immediately above the declaration is `*/`).
function docCommentStart(lines: LineInfo[], declLine: number): number {
  let i = declLine - 1;
  if (i < 0) return declLine;
  const prevRaw = lines[i].text.trim();
  if (prevRaw.length === 0) return declLine;
  // Contiguous // block: walk back through all consecutive // lines
  if (prevRaw.startsWith('//')) {
    while (i > 0 && lines[i - 1].text.trim().startsWith('//')) i--;
    return i;
  }
  // Single-line /* */ block
  if (prevRaw.startsWith('/*')) return i;
  // End of multi-line /* */ block: walk back from */ to the opening /*.
  // Do NOT stop on blank lines — they can appear inside the comment block itself.
  if (prevRaw.startsWith('*/') || prevRaw.endsWith('*/')) {
    let j = i;
    while (j >= 0) {
      if (lines[j].text.trim().startsWith('/*')) return j;
      j--;
    }
    // No /* found — malformed comment; don't attach
  }
  return declLine;
}

// Span ends just before the next top-level construct. A top-level comment line (// or /*) is
// treated as a boundary because it may be the doc comment of the following declaration.
// Without this, span A would swallow B's doc comment, causing overlapping spans.
function spanEnd(lines: LineInfo[], declLine: number): number {
  let endLine = lines.length - 1;
  for (let i = declLine + 1; i < lines.length; i++) {
    if (!isAtTopLevel(lines[i])) continue;
    const eff = lines[i].effective.trim();
    const raw = lines[i].text.trim();
    if (eff.length > 0 || raw.startsWith('//') || raw.startsWith('/*')) {
      endLine = i - 1;
      while (endLine > declLine && lines[endLine].text.trim().length === 0) endLine--;
      break;
    }
  }
  return lines[endLine].start + lines[endLine].text.length;
}

type SignatureMode = 'function' | 'type_body' | 'logical_line';

// Extract signature.
// 'function'     — scan for body '{'; struct/interface preceding { = inline return type, skip it.
// 'type_body'    — scan for body '{'; any { at depth 0 is the body opener (no return-type exceptions).
// 'logical_line' — return effective header line directly (const / var / type alias / grouped).
function extractSignature(lines: LineInfo[], declLine: number, end: number, mode: SignatureMode): string {
  if (mode === 'logical_line') return lines[declLine].effective.trim();
  const sigState = makeState();
  const sigLines: string[] = [];
  let foundBrace = false;

  for (let i = declLine; i < lines.length && lines[i].start <= end; i++) {
    const text = lines[i].text;
    let partial = '';
    let j = 0;
    while (j < text.length) {
      const ch = text[j];
      if (sigState.inBlockComment) {
        if (ch === '*' && text[j + 1] === '/') { sigState.inBlockComment = false; j += 2; } else j++;
        continue;
      }
      if (sigState.inRawString) { if (ch === '`') sigState.inRawString = false; j++; continue; }
      if (sigState.inInterpString) { if (ch === '\\') { j += 2; continue; } if (ch === '"') sigState.inInterpString = false; j++; continue; }
      if (sigState.inRune) { if (ch === '\\') { j += 2; continue; } if (ch === "'") sigState.inRune = false; j++; continue; }
      if (ch === '/' && text[j + 1] === '/') break;
      if (ch === '/' && text[j + 1] === '*') { sigState.inBlockComment = true; j += 2; continue; }
      if (ch === '`') { sigState.inRawString = true; partial += ch; j++; continue; }
      if (ch === '"') { sigState.inInterpString = true; partial += ch; j++; continue; }
      if (ch === "'") { sigState.inRune = true; partial += ch; j++; continue; }
      if (ch === '{' && sigState.braceDepth === 0 && sigState.parenDepth === 0 && sigState.bracketDepth === 0) {
        if (mode === 'function') {
          // In function mode only: struct/interface before { signals an inline return type,
          // not the function body opener.
          const lastToken = partial.trimEnd().match(/\b(\w+)$/)?.[1] ?? '';
          if (lastToken === 'struct' || lastToken === 'interface') {
            // Peek: if immediately closed (e.g. interface{}), include {} and continue scanning
            let k = j + 1;
            while (k < text.length && text[k] === ' ') k++;
            if (k < text.length && text[k] === '}') {
              partial += ch; j++;
              while (j < text.length && text[j] === ' ') { partial += text[j]; j++; }
              if (j < text.length) { partial += text[j]; j++; }
              continue;
            }
            // Non-empty inline composite type (e.g. struct{ V int }): track depth and continue
            sigState.braceDepth++;
            partial += ch;
            j++;
            continue;
          }
        }
        // type_body mode, or function mode without preceding struct/interface: body opener
        partial += ch;
        foundBrace = true;
        break;
      }
      if (ch === '{') sigState.braceDepth++;
      else if (ch === '}' && sigState.braceDepth > 0) sigState.braceDepth--;
      else if (ch === '(') sigState.parenDepth++;
      else if (ch === ')' && sigState.parenDepth > 0) sigState.parenDepth--;
      else if (ch === '[') sigState.bracketDepth++;
      else if (ch === ']' && sigState.bracketDepth > 0) sigState.bracketDepth--;
      partial += ch;
      j++;
    }
    sigLines.push(partial);
    if (foundBrace) break;
  }

  if (!foundBrace) return lines[declLine].effective.trim();
  return sigLines.join('\n');
}

// ─── name extraction ──────────────────────────────────────────────────────────

// Extract all declared names from a const/var/type declaration line or group member line.
// Handles: `A = 1`, `A, B = 1, 2`, `X int`, `X, Y int`, `A int = 1`.
// Splits at the first `=` or `:` to get the LHS, then splits by comma.
function extractNamesFromDecl(text: string): string[] {
  const lhs = text.split(/\s*[=:]/)[0];
  return lhs
    .split(',')
    .map(s => s.trim().match(/^([A-Za-z_][A-Za-z0-9_]*)/)?.[1])
    .filter((n): n is string => !!n && n !== '_');
}

// Classify a non-grouped type declaration as 'class' (struct or interface) or 'type' (alias/other).
// afterName is the effective text on the declaration line immediately after the type name.
// If afterName starts with '[', a bracket-depth counter scans forward to find the matching ']',
// continuing onto subsequent lines for multi-line type-parameter lists.
// Uses bracket depth (not indexOf) so nested brackets like ~[16]byte are handled correctly.
function classifyTypeKind(lines: LineInfo[], startLine: number, afterName: string): 'class' | 'type' {
  if (!afterName.startsWith('[')) {
    return (afterName.startsWith('struct') || afterName.startsWith('interface')) ? 'class' : 'type';
  }
  let depth = 0;
  // First pass: within afterName (the remainder of the declaration line)
  for (let j = 0; j < afterName.length; j++) {
    if (afterName[j] === '[') depth++;
    else if (afterName[j] === ']') {
      depth--;
      if (depth === 0) {
        const rest = afterName.slice(j + 1).trimStart();
        return (rest.startsWith('struct') || rest.startsWith('interface')) ? 'class' : 'type';
      }
    }
  }
  // Second pass: multi-line type-parameter list — scan subsequent effective lines
  for (let i = startLine + 1; i < lines.length; i++) {
    const seg = lines[i].effective;
    for (let j = 0; j < seg.length; j++) {
      if (seg[j] === '[') depth++;
      else if (seg[j] === ']') {
        depth--;
        if (depth === 0) {
          const rest = seg.slice(j + 1).trimStart();
          return (rest.startsWith('struct') || rest.startsWith('interface')) ? 'class' : 'type';
        }
      }
    }
  }
  return 'type'; // malformed or unrecognized
}

// Collect declared names from a `const (` / `var (` / `type (` group body.
// Only processes lines at direct group depth (parenDepthBefore===1, brace/bracket===0).
// This prevents inner method signatures or nested call arguments from being treated as
// group members, and prevents a nested `)` (e.g. inside `fn(1,)`) from terminating the group.
function parseGroupedNames(lines: LineInfo[], startLine: number): string[] {
  const names: string[] = [];
  for (let i = startLine + 1; i < lines.length; i++) {
    const line = lines[i];
    if (line.parenDepthBefore !== 1 || line.braceDepthBefore !== 0 || line.bracketDepthBefore !== 0) continue;
    const eff = line.effective.trim();
    if (eff === '') continue;
    if (eff === ')' || eff.startsWith(')')) break;
    names.push(...extractNamesFromDecl(eff));
  }
  return names;
}

// ─── helpers ─────────────────────────────────────────────────────────────────

// Returns text with comment regions replaced by spaces, preserving string literals intact
// (including // and /* that appear inside "..." or `...`). Tracks interpreted and raw string
// state so that comment-like sequences inside strings are not masked. Used for safe import-path
// extraction; rune literals are not tracked because import paths are always "...".
function maskComments(text: string, startInBlock: boolean): string {
  let out = '';
  let i = 0;
  let inBlock = startInBlock;
  let inStr = false;   // inside "..."
  let inRaw = false;   // inside `...`
  while (i < text.length) {
    if (inBlock) {
      if (text[i] === '*' && text[i + 1] === '/') { out += '  '; i += 2; inBlock = false; }
      else { out += ' '; i++; }
    } else if (inStr) {
      if (text[i] === '\\') { out += text[i]; out += text[i + 1] ?? ''; i += 2; }
      else if (text[i] === '"') { out += text[i]; i++; inStr = false; }
      else { out += text[i]; i++; }
    } else if (inRaw) {
      if (text[i] === '`') { out += text[i]; i++; inRaw = false; }
      else { out += text[i]; i++; }
    } else {
      if (text[i] === '/' && text[i + 1] === '/') {
        while (i < text.length) { out += ' '; i++; }
      } else if (text[i] === '/' && text[i + 1] === '*') {
        out += '  '; i += 2; inBlock = true;
      } else if (text[i] === '"') {
        out += text[i]; i++; inStr = true;
      } else if (text[i] === '`') {
        out += text[i]; i++; inRaw = true;
      } else {
        out += text[i]; i++;
      }
    }
  }
  return out;
}

function isUppercase(name: string): boolean {
  if (!name) return false;
  const ch = String.fromCodePoint(name.codePointAt(0)!);
  return ch === ch.toUpperCase() && ch !== ch.toLowerCase();
}

// ─── analyzer ────────────────────────────────────────────────────────────────

export function analyzeGo(content: string, file: string): SourceAnalysis {
  const isTestFile = file.endsWith('_test.go');
  const lines = toLines(content);
  const declarations: SourceDeclaration[] = [];
  const imports: ParsedImport[] = [];
  let inImportBlock = false;

  for (let i = 0; i < lines.length; i++) {
    const line = lines[i];

    // ── Import block: checked BEFORE isAtTopLevel because member lines have parenDepthBefore=1 ──
    if (inImportBlock) {
      const eff = line.effective.trim();
      if (eff === ')' || eff.startsWith(')')) { inImportBlock = false; continue; }
      // maskComments handles all comment cases: inBlockCommentBefore covers the line-opens-inside
      // a block comment case; it also handles "/* opens here" and ": // comment" on same line.
      const m = maskComments(line.text, line.inBlockCommentBefore).match(/"([^"]+)"/);
      if (m) imports.push({ kind: 'static_import', specifier: m[1], start: line.start, end: line.start + line.text.length });
      continue;
    }

    if (!isAtTopLevel(line)) continue;
    const eff = line.effective.trim();
    if (eff === '') continue;

    // ── Single-line import ────────────────────────────────────────────────────
    if (eff.startsWith('import ') || eff === 'import(') {
      const rest = eff.slice('import'.length).trim();
      if (rest === '(' || rest.startsWith('(')) {
        inImportBlock = true;
      } else {
        // maskComments handles `import /* "fake" */ "fmt"` and `import // "fake"\n"fmt"` (latter impossible but safe)
        const m = maskComments(line.text, false).match(/"([^"]+)"/);
        if (m) imports.push({ kind: 'static_import', specifier: m[1], start: line.start, end: line.start + line.text.length });
      }
      continue;
    }

    // ── Declaration parsing ───────────────────────────────────────────────────
    const isFuncDecl = eff.startsWith('func ') || eff === 'func(';
    const isTypeDecl = !isFuncDecl && (eff.startsWith('type ') || eff === 'type(');
    const isConstDecl = !isFuncDecl && !isTypeDecl && (eff.startsWith('const ') || eff === 'const(');
    const isVarDecl = !isFuncDecl && !isTypeDecl && !isConstDecl && (eff.startsWith('var ') || eff === 'var(');

    if (!isFuncDecl && !isTypeDecl && !isConstDecl && !isVarDecl) continue;

    let kind: SourceDeclarationKind;
    let name: string;
    let search_names: string[];

    if (isFuncDecl) {
      const methodMatch = eff.match(/^func\s+\(\s*(?:[A-Za-z_][A-Za-z0-9_]*)?\s*\*?\s*([A-Za-z_][A-Za-z0-9_]*)(?:\[[^\]]*\])?\s*\)\s+([A-Za-z_][A-Za-z0-9_]*)/);
      if (methodMatch) {
        name = methodMatch[2];
        search_names = [methodMatch[2], `${methodMatch[1]}.${methodMatch[2]}`];
      } else {
        const plainMatch = eff.match(/^func\s+([A-Za-z_][A-Za-z0-9_]*)/);
        if (!plainMatch) continue;
        name = plainMatch[1];
        search_names = [name];
      }
      kind = 'function';

    } else if (isTypeDecl) {
      const afterType = eff.slice('type'.length).trim();
      if (afterType.startsWith('(')) {
        const names = parseGroupedNames(lines, i);
        if (names.length === 0) continue;
        name = names[0];
        search_names = names;
        kind = 'type';
      } else {
        const m = afterType.match(/^([A-Za-z_][A-Za-z0-9_]*)/);
        if (!m) continue;
        name = m[1];
        search_names = [name];
        kind = classifyTypeKind(lines, i, afterType.slice(name.length).trimStart());
      }

    } else {
      const keyword = isConstDecl ? 'const' : 'var';
      const afterKeyword = eff.slice(keyword.length).trim();
      if (afterKeyword.startsWith('(')) {
        const names = parseGroupedNames(lines, i);
        if (names.length === 0) continue;
        name = names[0];
        search_names = names;
      } else {
        const names = extractNamesFromDecl(afterKeyword);
        if (names.length === 0) continue;
        name = names[0];
        search_names = names;
      }
      kind = 'variable';
    }

    const docStart = docCommentStart(lines, i);
    const end = spanEnd(lines, i);
    const sigMode: SignatureMode =
      isFuncDecl ? 'function' :
      (isTypeDecl && kind === 'class') ? 'type_body' :
      'logical_line';
    const sig = extractSignature(lines, i, end, sigMode);
    // All declarations in _test.go files get kind='test', regardless of their syntactic form.
    const finalKind: SourceDeclarationKind = isTestFile ? 'test' : kind;
    declarations.push({
      kind: finalKind, name, search_names,
      start: lines[docStart].start,
      end,
      signature: sig,
      exported: isTestFile ? false : isUppercase(name)
    });
  }

  // Exports: functions (including methods) contribute only d.name — search aliases like
  // 'Repo.Save' are excluded. All other kinds contribute all search_names (handles grouped
  // const/var/type where every name in the list is a first-class declared identifier).
  const exportNames: string[] = [];
  for (const d of declarations) {
    if (isTestFile || d.kind === 'test') continue;
    if (d.kind === 'function') {
      exportNames.push(d.name);
    } else {
      exportNames.push(...d.search_names);
    }
  }
  const exports = [...new Set(exportNames.filter(isUppercase))].sort();

  return {
    imports,
    exports,
    declarations: declarations.sort((a, b) => a.start - b.start || a.name.localeCompare(b.name))
  };
}

// ─── parser ──────────────────────────────────────────────────────────────────

const GO_EXTENSIONS = ['.go'] as const;

export const goParser: LanguageParser = {
  id: 'go',
  extensions: GO_EXTENSIONS,
  analyze: analyzeGo,
  resolveImport(
    _importer: string,
    specifier: string,
    { sourceFiles, goModulePath }: ImportResolutionContext
  ): ImportResolution {
    if (!goModulePath) return { status: 'external' };
    let pkgDir: string;
    if (specifier === goModulePath) {
      pkgDir = '';
    } else if (specifier.startsWith(goModulePath + '/')) {
      pkgDir = specifier.slice(goModulePath.length + 1);
    } else {
      return { status: 'external' };
    }
    const paths: string[] = [];
    for (const f of sourceFiles) {
      if (!f.endsWith('.go') || f.endsWith('_test.go')) continue;
      const dir = f.includes('/') ? f.slice(0, f.lastIndexOf('/')) : '';
      if (dir === pkgDir) paths.push(f);
    }
    paths.sort();
    return paths.length > 0 ? { status: 'resolved', paths } : { status: 'unresolved_local' };
  }
};
```
